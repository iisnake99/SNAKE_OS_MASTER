# SNAKE OS — FINAL iPhone VERSION

This package is ready for free GitHub Pages hosting.

Files:
- index.html — SNAKE OS MASTER
- manifest.webmanifest — installable web-app settings
- sw.js — offline cache
- snake-icon.svg — app icon
- README.txt — quick setup

IMPORTANT:
The local HTML file you opened from Files is only a preview on iPhone. It is not the correct way to run JavaScript apps.

Use GitHub Pages (free) to give SNAKE OS a normal HTTPS web address. Then open that address in Safari and use:
Share -> Add to Home Screen

No paid hosting is required.

QUICK SETUP:
1. Create a new GitHub repository named: snake-os
2. Upload ALL files from this folder to the repository root.
3. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
4. Wait for GitHub Pages to publish.
5. Open the Pages URL in Safari.
6. Share -> Add to Home Screen.
7. Launch SNAKE OS from the new home-screen icon.

The app remains local-first: its lead data is stored in the browser. External actions still require your permission.
